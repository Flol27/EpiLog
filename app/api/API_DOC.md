# API Documentation

## /api/users
- GET --> all users
- GET ?\[email / firstname / lastname\]--> user with this spezific email/firstname/lastname
> Example
> /api/users?email=test@example.com
- POST --> Crete new User

## /api/users/\[id\]
- GET --> User with spzific id
- DELETE --> Delete User with specific id
- PUT --> Update User with specific id
